Weather Wear 🌤️👕

Weather Wear is a simple web app that shows the current weather and gives clothing suggestions based on your geolocation or a city you choose.

Features:

Get weather for your current location or any city.

Shows temperature, weather description, humidity, and wind speed.

Provides simple clothing recommendations based on the weather.

Built with HTML, CSS, and JavaScript.


How It Works

Fetches weather data from the OpenWeather API.

Users can allow geolocation access or enter a city manually.

Gives clothing suggestions like jackets for cold weather or light clothes for hot weather.


API Key

You need an OpenWeather API key. Replace the key in your JavaScript file with your own:

const apiKey = "YOUR_API_KEY_HERE";
